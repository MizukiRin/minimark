# ✨ MiniMark - 极简 Windows 桌面 Markdown 编辑与查看器

> 一款基于 **PySide6 + 现代前端渲染架构** 的 Windows 桌面级极简 Markdown 工具。  
> 目标方便自己使用，借由antigravity开发。

---

## 🌟 核心特性一览

### 1. 🎨 极简美学
- **呼吸感留白**：克制优雅的界面设计，全量采用 1.5px 纤细矢量 SVG 线条图标，彻底消除视觉杂乱。
- **系统深浅色自动跟随**：深度打通 Windows 系统注册表，毫秒级响应深色/浅色模式切换，亦支持随时手动一键切换。
- **中英双语 (i18n)**：全量 UI 元素、提示、右键菜单无缝支持简体中文与英文。

### 2. 💊 右上角悬浮模式切换胶囊
主窗口右上角常驻高斯模糊磨砂半透明胶囊，默认进入沉浸式【仅查看模式】，点击自由流转：
- **👁 仅查看模式 (默认)**：纯净排版，享受无干扰阅读。
- **◫ 双栏对照模式**：左侧源码编辑，右侧实时渲染，支持高精度比例双向平滑同步滚动。
- **✎ 仅编辑模式**：全宽代码编辑视窗，专注内容创作。

### 3. 🏠 无页签主页 Dashboard 与最近记录
- **优雅回退主页**：关闭所有标签页时不强制弹出无用草稿，而是平滑过渡至应用主页。
- **最近访问直达**：主页直观展示「最近打开的文件夹」与「最近打开的文件」，基于 `localSyorage` 本地持久化，秒级点击直达。

### 4. 🛡️ 未保存安全防御体系 (Unsaved Guard)
- **三按钮确认模态弹窗**：关闭含有未保存修改的页签时弹出磨砂模态对话框 `[ 取消 | 不保存 | 保存 ]`。
- **不保存彻底清除**：选择【不保存】时，安全关闭标签页并**彻底从左侧工作区目录树中移除该临时草稿**。

### 5. 🗂️ 像素级对齐工作区与智能保存流
- **固定槽位对齐**：目录树统一采用 `[ 14px 展开槽 + 6px 间隙 + 15px 图标槽 + 6px 间隙 + 弹性文字 ]` 严格对齐规范。
- **临时草稿与正式目录分割**：置顶临时文件与打开的工作区文件夹之间以浅色横线清晰分隔。
- **智能保存流**：
  - 用户**主动保存临时文件 (`Ctrl+S`)**：工作区自动切换加载为保存所在的文件夹目录。
  - **关闭页签弹窗中点击【保存】**：文件写入本地后直接关闭页签，工作区保持原状不切换。
  - **在已打开的工作区文件夹中修改文件**：保存后工作区始终保持当前工作区不变。

### 6. 📐 全面排版与科学公式图表支持 (100% 离线)
- **GFM 现代排版**：标题、表格、引用块、有序/无序列表、删除线、超链接。
- **KaTeX 数学公式**：原生支持行内公式 `$E=mc^2$` 与块级复杂公式 `$$\int_{-\infty}^{+\infty} e^{-x^2} dx = \sqrt{\pi}$$`。
- **Mermaid.js 图表**：原生支持流程图 (Flowchart)、时序图 (Sequence)、甘特图、类图等实时可视化。
- **Prism 代码高亮与复制**：多语言语法高亮，代码块右上角一键复制。
- **交互式复选框**：预览区直接点击 `- [ ]` / `- [x]` 任务列表，自动双向回写源码。

### 7. 🔍 全文黄色高亮与居中搜索替换
- **无损黄色高亮**：基于 TreeWalker 文本节点遍历算法，精准高亮所有匹配项。
- **焦点居中对齐**：当前激活项橙色加重高亮并平滑居中滚动至视窗中心。
- **快捷导航**：支持 `Enter` (下一个) 与 `Shift+Enter` (上一个) 循环查找，支持 `Ctrl+H` 查找与批量替换。

## 📂 项目结构说明

```
markdown_app/
├── main.py                     # 主程序入口 (PySide6 + QWebEngineView + QtWebChannel)
├── backend.py                  # Python 后端桥接服务 (文件读写/工作区遍历/系统主题/路径管理)
├── MiniMark.spec               # 独立应用打包规格配置
├── version_info.txt            # Windows 文件版本定义
├── requirements.txt            # Python 依赖库
├── README.md                   # 项目使用与说明文档
├── assets/                     # 高清矢量图标包 (.ico / .png)
└── ui/                         # 纯本地化离线前端渲染核心
    ├── index.html              # 极简 DOM、Home Dashboard、三按钮模态弹窗
    ├── style.css               # 风格样式、高斯模糊遮罩与目录树对齐
    ├── app.js                  # 前端核心控制器 (保存流/标签管理/搜索高亮/滚动联动)
    └── libs/                   # 100% 离线依赖库 (零外网延迟，即开即用)
        ├── qwebchannel.js      # QtWebChannel 通信库
        ├── marked.min.js       # GFM Markdown 解析库
        ├── mermaid.min.js      # Mermaid.js 图表引擎
        ├── katex/              # KaTeX LaTeX 数学公式渲染库
        └── prism/              # Prism.js 代码高亮库
```

## 🚀 运行与启动

### 1. 直接运行独立发布版（推荐）
在 release 中直接双击 **`MiniMark.exe`** 即可极速启动。

### 2. 开发者源码运行
推荐使用 Python 3.10+ 环境：
```bash
pip install -r requirements.txt
python main.py
```

## ⌨️ 常用快捷键一览

| 快捷键 | 功能描述 | 交互响应 |
| :--- | :--- | :--- |
| `Ctrl + N` | 新建临时文件 | 在工作区置顶生成草稿，**自动进入纯编辑模式并聚焦光标** |
| `Ctrl + O` | 打开本地 Markdown 文件 | 调出系统文件选择框，加载并展示文档 |
| `Ctrl + K Ctrl + O` | 打开工作区文件夹 | 调出系统文件夹选择框，递归加载并展开目录树 |
| `Ctrl + S` | 保存当前文档 | 主动保存临时文件时自动将所在目录加载为工作区；已有文件保存则工作区保持不变 |
| `Ctrl + Shift + S` | 另存为... | 弹出路径选择，主动另存临时文件时切换工作区 |
| `Ctrl + W` | 关闭当前标签页 | 有未保存内容时弹出三按钮确认弹窗；全部关闭后进入主页 |
| `Escape` (在弹窗中) | 取消弹窗 | 关闭未保存确认弹窗并停留在当前文档 |
| `Ctrl + B` | 展开 / 折叠侧边栏 | 快速切换左侧工作区目录栏的显示与隐藏 |
| `Ctrl + F` | 查找文本 | 唤出搜索栏，黄色高亮文档中所有匹配项 |
| `Ctrl + H` | 查找与替换 | 唤出搜索与替换栏，支持单次替换与全部替换 |
| `Enter` (在搜索框中) | 查找下一个 | 橙色高亮下一个匹配项并平滑居中滚动 |
| `Shift + Enter` (在搜索框中) | 查找上一个 | 橙色高亮上一个匹配项并平滑居中滚动 |
| `Ctrl + 1` | 切换为【仅编辑】 | 全宽源码编辑视窗 |
| `Ctrl + 2` | 切换为【双栏】 | 左侧编辑、右侧实时渲染对照视窗 |
| `Ctrl + 3` | 切换为【仅查看】 | 纯净沉浸排版视窗 |
