# ✨ MiniMark - 极简 Windows 桌面 Markdown 编辑与查看器 (v2.0)

> 一款基于 **PySide6 + 现代前端渲染架构** 的 Windows 桌面级极简 Markdown 工具。  
> 汲取 **Typora 纯净排版美学**，彻底摒弃繁复工具栏干扰，让用户回归纯粹的书写与沉浸式阅读。

---

## 🌟 核心特性一览

### 1. 🎨 Typora 级极简美学
- **呼吸感留白**：克制优雅的界面设计，全量采用 1.5px 纤细矢量 SVG 线条图标，彻底消除视觉杂乱。
- **系统深浅色自动跟随**：深度打通 Windows 系统注册表，毫秒级响应深色/浅色模式切换，亦支持随时手动一键切换。
- **中英双语 (i18n)**：全量 UI 元素、提示、右键菜单无缝支持简体中文与英文。

### 2. 💊 右上角悬浮模式胶囊 & 语法速查提示
- **悬浮模式切换**：主窗口右上角常驻高斯模糊磨砂半透明胶囊，默认进入沉浸式【仅查看模式】，点击自由流转：
  - **👁 仅查看模式 (默认)**：Typora 级纯净排版，享受无干扰阅读。
  - **◫ 双栏对照模式**：左侧源码编辑，右侧实时渲染，支持高精度比例双向平滑同步滚动。
  - **✎ 仅编辑模式**：全宽代码编辑视窗，专注内容创作。
- **📖 语法速查悬浮按钮**：模式胶囊下方新增极简提示按钮，一键呼出《Markdown语法速查.md》，全面展示公式、图表、高亮与排版样例。

### 3. 📑 工作区多级大纲 (TOC) 与悬浮大纲按钮
- **工作区大纲面板**：位于左侧工作区底部，点击大纲按钮展开（默认占据约 1/2 高度），可一键折叠隐藏。
- **自由上下拉拖拽**：支持通过分割条上下拖拽调节高度（限制最小 60px，最大占工作区 2/3 高度）。
- **实时层级解析与平滑跳转**：自动提取当前文档 H1~H6 标题层级，点击节点即可平滑滚动对齐至对应正文位置。

### 4. 💾 另存为与智能标题文件名提取
- **顶栏专属图标**：保存按钮旁新增【另存为...】独立图标按钮 (`Ctrl+Shift+S`)。
- **智能提取命名**：新建临时文件保存或已有文件另存为时，自动检测抓取最高一级的标题（优先 H1，其次 H2/H3...）作为默认文件名。

### 5. ⌨️ 源码编辑器 Tab 缩进与反缩进
- **专业缩进体验**：深度拦截 `Tab` 键，支持单光标 2 空格缩进，以及多行选中文本的批量 `Tab` 缩进与 `Shift+Tab` 反向缩进。

### 6. 🏠 无页签主页 Dashboard 与最近记录
- **优雅回退主页**：关闭所有标签页时不强制弹出无用草稿，而是平滑过渡至应用主页。
- **最近访问直达**：主页直观展示「最近打开的文件夹」与「最近打开的文件」，基于 `localStorage` 本地持久化，秒级点击直达。

### 7. 🛡️ 未保存安全防御体系 (Unsaved Guard)
- **三按钮确认模态弹窗**：关闭含有未保存修改的页签时弹出磨砂模态对话框 `[ 取消 | 不保存 | 保存 ]`。
- **不保存彻底清除**：选择【不保存】时，安全关闭标签页并**彻底从左侧工作区目录树中移除该临时草稿**。

### 8. 📐 全面排版与科学公式图表支持 (100% 离线)
- **GFM 现代排版**：标题、表格、引用块、有序/无序列表、删除线、超链接。
- **KaTeX 数学公式**：原生支持行内公式 `$E=mc^2$` 与块级复杂公式 `$$\int_{-\infty}^{+\infty} e^{-x^2} dx = \sqrt{\pi}$$`。
- **Mermaid.js 图表**：原生支持流程图 (Flowchart)、时序图 (Sequence)、甘特图、类图等实时可视化。
- **Prism 代码高亮与复制**：多语言语法高亮，代码块右上角一键复制。
- **交互式复选框**：预览区直接点击 `- [ ]` / `- [x]` 任务列表，自动双向回写源码。

## 📂 项目结构说明

本项目采用 **“公共 UI + 公共 Python Core 业务层 + 双版本独立外壳”** 的分层架构：

```
markdown_app/
├── assets/                     # 【公共】高清矢量图标包 (.ico / .png)
├── ui/                         # 【公共】纯本地化离线前端渲染核心 (HTML/CSS/JS/KaTeX/Mermaid)
│   └── app.js                  # 内置 Universal Bridge，自适应 Qt 与 pywebview
├── core/                       # 【公共核心】纯 Python 业务逻辑 (文件读写/工作区树/系统集成)
│   ├── file_manager.py         # 智能多编码识别(UTF-8/GBK等)、安全读写
│   ├── workspace_manager.py    # 递归目录树解析、增删重命名
│   └── system_helper.py        # Windows 注册表主题与语言检测、资源管理器定位
│
├── lite/                       # 【Lite 轻量版】基于 pywebview + Edge WebView2 (~24MB, 秒开)
│   ├── main_lite.py            # Lite 启动入口
│   ├── backend_lite.py         # Lite 桥接层
│   ├── run_lite.bat            # 一键运行脚本
│   └── build_lite.bat          # 一键打包脚本
│
├── classic/                    # 【Classic 原版】基于 PySide6 + QWebEngine (~520MB)
│   ├── main.py                 # Classic 启动入口
│   ├── backend.py              # Classic 桥接层
│   ├── run.bat                 # 一键运行脚本
│   └── build_classic.bat       # 一键打包脚本
│
├── run_lite.bat                # 根目录快速启动 Lite 版 (推荐)
├── run_classic.bat             # 根目录快速启动 Classic 原版
└── run.bat                     # 默认快速启动脚本
```

## 🚀 运行与启动

### 1. 直接运行 Lite 轻量版（推荐，秒开）
```bash
pip install -r lite/requirements_lite.txt
# 或直接双击 run_lite.bat
python lite/main_lite.py
```

### 2. 运行 Classic 原版 (PySide6)
```bash
pip install -r classic/requirements.txt
# 或直接双击 run_classic.bat
python classic/main.py
```

## ⌨️ 常用快捷键一览

| 快捷键 | 功能描述 | 交互响应 |
| :--- | :--- | :--- |
| `Ctrl + N` | 新建临时文件 | 在工作区置顶生成草稿，**自动进入纯编辑模式并聚焦光标** |
| `Ctrl + O` | 打开本地 Markdown 文件 | 调出系统文件选择框，加载并展示文档 |
| `Ctrl + K Ctrl + O` | 打开工作区文件夹 | 调出系统文件夹选择框，递归加载并展开目录树 |
| `Ctrl + S` | 保存当前文档 | 主动保存临时文件时自动提取顶级标题并将所在目录加载为工作区 |
| `Ctrl + Shift + S` | 另存为... | 弹出路径选择，自动提取最高级标题作为默认文件名 |
| `Tab` | 编辑器缩进 | 插入 2 空格缩进（支持单行与多行批量缩进） |
| `Shift + Tab` | 编辑器反向缩进 | 批量减少 2 空格缩进（支持单行与多行反向缩进） |
| `Ctrl + W` | 关闭当前标签页 | 有未保存内容时弹出三按钮确认弹窗；全部关闭后进入主页 |
| `Escape` (在弹窗中) | 取消弹窗 | 关闭未保存确认弹窗并停留在当前文档 |
| `Ctrl + B` | 展开 / 折叠侧边栏 | 快速切换左侧工作区目录栏的显示与隐藏 |
| `Ctrl + F` | 查找文本 | 唤出搜索栏，黄色高亮文档中所有匹配项 |
| `Ctrl + H` | 查找与替换 | 唤出搜索与替换栏，支持单次替换与全部替换 |
| `Ctrl + 1 / 2 / 3` | 切换模式 | 纯编辑 / 双栏 / 纯查看 |
