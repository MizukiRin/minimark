# MiniMark v2.0 大版本升级技术实现方案 (Implementation Plan)

本文档针对 MiniMark v2.0 重大功能升级进行架构设计与技术实施规划。

---

## 1. 升级需求概述与目标

用户在本次 v2.0 大版本中提出以下 5 项核心功能需求：
1. **工作区大纲 (TOC) 与悬浮大纲按钮**：
   - 工作区最下方新增大纲区域，平时隐藏；
   - 点击大纲按钮在工作区展开，默认占据工作区约 1/2 高度；
   - 支持上下拖拽分割条调节高度（限制最小 60px，最大占工作区 2/3 高度），支持展开后一键隐藏；
   - 实时解析当前 Markdown 文档的 H1~H6 标题层级，点击大纲项平滑滚动导航至对应内容。
2. **新增「另存为」独立图标按钮**：
   - 在顶部操作栏的【保存】图标旁边新增【另存为...】图标按钮，支持快捷键 `Ctrl+Shift+S`。
3. **智能标题提取命名**：
   - 新建文件首次保存及已有文件另存为时，自动检测并提取文档中最高一级的 Markdown 标题（优先 H1，其次 H2/H3...）自动带入作为保存对话框的默认文件名。
4. **编辑器 Tab 缩进与反缩进支持**：
   - 拦截源码编辑器的 Tab 键，支持单光标插入缩进（2 空格）及多行选中文本的批量 `Tab` 缩进与 `Shift+Tab` 反向缩进。
5. **右上角悬浮语法提示按钮与速查文档**：
   - 在右上角视窗模式切换胶囊下方增加一个极简悬浮提示按钮（`?` / 书本图标）；
   - 点击后自动打开/切换至《Markdown语法速查.md》，全面展示 Markdown 全套排版语法、KaTeX 数学公式、Mermaid 图表、代码高亮与表格等示例。

## 3. 拟修改与新增模块清单

### 3.1 前端核心界面与样式 (`ui/`)

#### [MODIFY] [`ui/index.html`](file:///e:/notesapp/markdown_app/ui/index.html)
1. **顶部操作栏**：在保存按钮旁增加【另存为】按钮（`app.handleSaveAsFile(true)`）；
2. **工作区大纲容器**：在左侧 `#sidebar` 底部增加 `#outline-splitter`（拖拽分割条）与 `#sidebar-outline` 容器（包含标题栏、关闭按钮与大纲树 `#outline-tree`）；
3. **大纲悬浮触发按钮**：在左下角/工作区工具栏增加大纲悬浮/切换按钮；
4. **右上角语法速查悬浮按钮**：在 `#mode-capsule` 悬浮胶囊正下方增加 `.floating-tips-btn`。

#### [MODIFY] [`ui/style.css`](file:///e:/notesapp/markdown_app/ui/style.css)
1. **大纲面板样式**：
   - `.sidebar-outline` 容器布局（`display: flex; flex-direction: column; overflow: hidden;`）；
   - `.outline-splitter` 拖拽样式（`cursor: row-resize; height: 5px;`）；
   - `.outline-node` 树节点缩进与高亮悬停效果（`H1: 8px, H2: 20px, H3: 32px...`）；
2. **另存为按钮样式**：顶栏图标对齐规范；
3. **语法速查悬浮按钮样式**：`.floating-tips-btn` 磨砂高斯模糊微质感、呼吸阴影与悬停放大。

#### [MODIFY] [`ui/app.js`](file:///e:/notesapp/markdown_app/ui/app.js)
1. **大纲解析与导航引擎**：
   - `extractHeadings(markdownText)`：高效正则匹配提取 Markdown 标题层级与位置；
   - `renderOutline()`：动态生成大纲树；点击节点时平滑滚动对齐预览区与源码区；
   - `toggleOutline()` / `initOutlineDrag()`：上下拖拽调节高度（限制在 60px ~ 2/3 sidebar 高度）；
2. **智能文件名提取算法**：
   - `extractSmartFilename(tab)`：自动匹配首个最高级标题（H1 > H2 > H3），清洗 Windows 非法字符（`\/:*?"<>|`），生成如 `我的笔记标题.md`；
   - 在 `handleSaveFile()` 与 `handleSaveAsFile()` 中应用该默认文件名；
3. **Tab 缩进核心**：
   - 监听 `editorTextarea` 的 `keydown` 事件，阻止默认失焦行为；
   - 支持单光标插入 2 空格缩进；支持多行选中文本的批量 `Tab` 缩进与 `Shift+Tab` 反向缩进；
4. **语法速查文档加载**：
   - `openMarkdownCheatSheet()`：内置详尽的 Markdown 排版语法、数学公式、图表范例文档。

## 4. 验证计划

### 4.1 功能与交互验证
1. **大纲展开与拖拽验证**：
   - 点击大纲悬浮按钮，验证大纲在工作区最下方展开（约 1/2 高度）；
   - 鼠标拖拽上方分割条，验证高度在 60px 至 2/3 之间平滑调整；
   - 点击大纲中的各级标题，验证右侧内容区能精准平滑滚动跳转；
   - 点击关闭按钮或再次点击大纲按钮，验证能正常隐藏。
2. **另存为按钮验证**：
   - 验证顶栏保存按钮右侧显示【另存为】图标；
   - 点击后能正常调出系统保存对话框。
3. **智能标题文件名提取验证**：
   - 新建临时文档，输入 `# 极简Markdown查看器设计` 与正文；
   - 按 `Ctrl+S` 或点击保存/另存为，验证保存对话框的默认文件名自动填入 `极简Markdown查看器设计.md`。
4. **Tab 缩进验证**：
   - 在编辑器单行按下 `Tab`，验证插入 2 个空格且光标位置正确；
   - 选中多行代码/文本，按下 `Tab` 验证全部向右缩进 2 空格；按下 `Shift+Tab` 验证批量向左反缩进。
5. **语法速查悬浮按钮验证**：
   - 点击右上角模式胶囊下方的 `?` 按钮，验证自动新建/切换至 `Markdown语法速查.md`；
   - 验证公式、图表、代码高亮均可完美渲染查看。
